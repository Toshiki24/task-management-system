# 2. 画面設計概要

本システムでは、プロジェクトおよびタスクを中心とした管理画面を提供する。

MVPでは以下の機能を実装対象とする。

* ログイン
* ユーザー管理
* プロジェクト管理
* プロジェクトメンバー管理
* タスク管理
* タスクコメント

以下はPhase 2以降の追加機能とする。

* ダッシュボード
* タスク検索・絞り込み
* タスクステータス履歴
* ページング
* その他の拡張機能

# 21. 権限制御

画面上の操作について、ユーザー権限に応じて表示・操作可否を制御する。

| 操作       | 管理者 | OWNER | MEMBER |
| -------- | --: | ----: | -----: |
| プロジェクト参照 |   ○ |     ○ |      ○ |
| プロジェクト作成 |   ○ |     ○ |      △ |
| プロジェクト編集 |   ○ |     ○ |      × |
| プロジェクト削除 |   ○ |     ○ |      × |
| メンバー参照   |   ○ |     ○ |      ○ |
| メンバー追加   |   ○ |     ○ |      × |
| メンバー削除   |   ○ |     ○ |      × |
| タスク参照    |   ○ |     ○ |      ○ |
| タスク作成    |   ○ |     ○ |      ○ |
| タスク編集    |   ○ |     ○ |      ○ |
| タスク削除    |   ○ |     ○ |      △ |
| コメント投稿   |   ○ |     ○ |      ○ |

※最終的な認可判定はバックエンドAPI側で実施する。

フロントエンドでボタンを非表示にしても、セキュリティ対策にはならないため、API側で必ず権限チェックを行う。
