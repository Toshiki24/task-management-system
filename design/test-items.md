## 3. 記入方法

各テスト項目について、実施後に以下を記入する。

| 列       | 記入内容                                  |
| ------- | ------------------------------------- |
| 結果      | `OK` または `NG` を記入する                   |
| NG内容    | 結果が`NG`の場合、実際の挙動・エラー内容を記載する            |
| 修正内容    | 結果が`NG`の場合、原因および実施した修正内容を記載する（未修正なら「対応中」等） |

テスト方法（手順）に記載のコマンド例は、ローカル開発環境（`docker compose up -d` でDB起動、バックエンドは `http://localhost:5000`、フロントエンドは `http://localhost:3000`）を前提とする。
